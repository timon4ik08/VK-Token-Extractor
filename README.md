VK Token Extractor 🔑
Chrome расширение для безопасного извлечения access token из VK.com

📖 Описание
VK Token Extractor - это простое и безопасное расширение для Google Chrome, которое позволяет извлекать access token из вашей активной сессии VK.com. Расширение работает только с вашими данными и не передает их третьим лицам.

🚀 Возможности
🔍 Автоматическое обнаружение токенов в localStorage VK

📋 Легкое копирование токена в буфер обмена

🧪 Проверка валидности токена через VK API

🔒 Безопасность - все операции выполняются локально

🎯 Простой интерфейс - всего несколько кликов

📦 Установка
Установка из исходного кода
Скачайте или клонируйте репозиторий

bash
git clone https://github.com/your-username/vk-token-extractor.git
Откройте Chrome и перейдите в управление расширениями

Введите в адресной строке: chrome://extensions/

Или через меню: Настройки → Дополнительные инструменты → Расширения

Включите режим разработчика

Переключите тумблер "Режим разработчика" в правом верхнем углу

Загрузите расширение

Нажмите кнопку "Загрузить распакованное расширение"

Выберите папку с файлами расширения

Проверьте установку

В тулбаре Chrome должна появиться иконка расширения 🔑

🛠️ Использование
Откройте VK.com в браузере и авторизуйтесь

Нажмите на иконку расширения в тулбаре Chrome

Нажмите "Извлечь токен" - расширение найдет access token

Скопируйте токен кнопкой "📋 Скопировать токен"

Проверьте токен (опционально) кнопкой "🧪 Проверить токен"

🔧 Технические детали
Разрешения
Расширение запрашивает минимально необходимые разрешения:

activeTab - доступ к активной вкладке

scripting - выполнение скриптов на странице VK

https://vk.com/* - доступ к домену VK

Безопасность
✅ Локальная обработка - все данные обрабатываются в вашем браузере

✅ Без внешних запросов - кроме проверки токена через официальное VK API

✅ Прозрачный код - весь исходный код открыт для проверки

✅ Минимальные разрешения - только то, что необходимо для работы
