## 📖 Описание

**VK Token Extractor** — лёгкое и безопасное расширение для **Google Chrome**, позволяющее быстро извлечь **access token** из вашей активной сессии **VK.com**.

Все операции выполняются **исключительно локально** в браузере, без отправки данных на сторонние серверы.

---

## ✨ Особенности

- 🔍 Автоматическое обнаружение токенов на страницах VK  
- 📋 Копирование токена в буфер обмена одной кнопкой  
- 🧪 Проверка валидности токена через VK API  
- 🔒 Полностью локальная обработка (без сторонних серверов)  
- 🎨 Простой, чистый и интуитивный интерфейс
